# Проверки 02.11.2026: подтверждённые результаты и внешний блокер

Статус partial, productionApproved=false. Финальный комплект к эксплуатации не выпущен.

## Подтверждено

- Модели OCR после проверки SHA-256 доступны UID 10001 с правами 0644. Изменены права новых и ранее установленных моделей; права секретов и sandbox не ослаблялись.
- Реальный ClamAV со свежей официальной базой допустил PDF. OCR, публикация и поиск на трёх системах письма прошли; EICAR отклонён до парсера; целостность и отзыв доступа через корзину проверены.
- Зашифрованные потоки проверены до восстановления. PostgreSQL и частные файлы восстановлены в независимые тома одного хоста. Совпали дайджесты девяти бизнес-таблиц и одного файла. Это ограниченный синтетический набор: две разные редакции/история массового импорта этим набором не доказаны.
- В восстановленной PostgreSQL штатный recover_processing --workers-stopped --invalidate-sessions отозвал прежний сеанс. Прежние пароль и TOTP успешно приняты настоящим Django request client. Это не браузерная проверка восстановления и не второй физический сервер.
- В браузере HR сохранение даты окончания, перезагрузка и повторное отображение прошли; очистка дала NULL в PostgreSQL. Значение 12:30 по Ташкенту сохранено как 07:30 UTC. Проверены исправление lifecycle редактора и сохранение новости. Полный браузерный проход трёх ролей ещё не завершён.

## Безопасность конечных образов

Новые реальные Trivy-сканы: API — 0 Critical/46 High; worker — 1 Critical/81 High. Результаты и точные ID образов находятся в verification/2026-11-02-live-gates.json. Исправление интерфейса уже включено в API-кандидат. Последний дополнительный обработчик даты добавлен после сборки worker-кандидата; пересборка обязательна перед выпуском. Образы не равны будущему финальному релизу.

По проверенным страницам Debian текущая trixie остаётся уязвимой для libxml2 и ряда других пакетов. Для нескольких CVE Tesseract исправленного релиза ещё нет. Поставляются закреплённые модели с проверкой хешей, загрузка пользовательских .traineddata не предусмотрена. Это ограничивает соответствующий путь атаки, но не является устранением CVE или исключением из strict gate.

- [libxml2 Critical](https://security-tracker.debian.org/tracker/CVE-2026-6653)
- [Tesseract: нет исправленного релиза](https://security-tracker.debian.org/tracker/CVE-2026-88047)
- [Tesseract: LSTM model parsing](https://security-tracker.debian.org/tracker/CVE-2026-88048)
- [libxml2: исправления в другой ветке](https://security-tracker.debian.org/tracker/CVE-2026-86138)

Все записи High/Critical сохранены, подавления не добавлены. Не все пути эксплуатации воспроизведены; наличие библиотеки не доказывает доступную через портал атаку. Самостоятельная замена ABI системных библиотек или переход на testing/unstable без отдельной проверки не объявляются безопасным исправлением.

Для закрытия строгого допуска нужны совместимые исправленные пакеты/проверенная новая базовая среда, повторные сборки и сканы. Внешний блокер безопасности остаётся открытым. Проверки DNS/VPN/TLS компании, независимый пентест и восстановление на другом физическом сервере не выполнены.
