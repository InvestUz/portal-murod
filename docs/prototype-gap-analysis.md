# Прототип v3 → рабочая реализация

| Возможность v3 | Решение |
| --- | --- |
| Редакционная главная, карточки, переходы | Сохранить концепцию, реализовать новым адаптивным UI |
| Данные localStorage | Удалить как источник данных; PostgreSQL на сервере |
| Переключатель demo-ролей | Удалить; настоящие аккаунты и сессии |
| HR-only кадровые операции, редактор | Изменить: HR/ADMIN ведут данные и контент; EMPLOYEE имеет строго ограниченный self-service |
| Офис/этаж/кабинет/место | Один обязательный офис; этаж/кабинет необязательны; номер места не нужен |
| CSV в браузере | Контролируемый серверный CSV/XLSX preview/commit с проверкой файлов |
| Ссылка на документ | Карточка/неизменяемые версии, карантин, поиск реквизитов и OCR |
| Учёт прочтения | Только уникальные открытия полной новости; подтверждения ознакомления нет |
| Настройки приватности | Серверная проекция и поиск по разрешённым данным, без года рождения для EMPLOYEE |

Прототип не содержит серверной авторизации/БД/настоящей защиты; его наличие не доказывает выполнение нового задания.
