# Исправления аудита — 0.3.0-rc.8

Дата: 02.11.2026 (Asia/Tashkent). **Общий статус: partial.** Все семь замечаний A01–A07 исправлены в коде; полноценная браузерная приёмка и устранение системных CVE не подтверждены. Это комплект исходников для ИТ, а не утверждение о выполненном production-развёртывании.

## Что исправлено

| Замечание | Изменение | Подтверждение |
|---|---|---|
| A01: старый файл/импорт | При выборе нового файла родительская форма сразу сбрасывает ссылку и предпросмотр. Ответ старой загрузки/предпросмотра не принимается. Подтверждение импорта отключено после изменения соответствия колонок до нового предпросмотра. | Тесты логики UploadBox, VersionForm, ImportForm; TypeScript |
| A02: даты новости | API и response-контракт возвращают expiresAt; форма подставляет обе даты в часовом поясе Ташкента и передаёт null при очистке. Неизменённые даты сохраняют исходную точность секунд. | Новый backend-тест read/clear, тест формы hydrate/save/clear и преобразования времени |
| A03: зависшая проверка файла | Последовательный polling без наложения запросов; сетевой отказ отображается с повторением. Ошибка обработки останавливает индикатор. Повторное сканирование перехватывает ошибку. | Тест ошибки polling и повторения; статический обзор terminal-состояний |
| A04: ложный успех API | HTML, null и примитивы вместо JSON-объекта/массива отклоняются через ApiError. Массивы сохранены для справочников и аккаунтов. | Негативные и положительные тесты текущего api.ts |
| A05: ошибки форм | Сводка показывает понятные подписи полей и сообщения валидации, получает фокус; ошибки импорта раскрываются построчно. Справочник сотрудников имеет сообщение и повтор загрузки. | TypeScript/ESLint, обзор обработки данных; браузерное объявление ошибок ещё не проверено |
| A06: потеря ввода | Формы предупреждают о закрытии после ввода, Escape/крестик/Отмена проходят общий guard. Во время отправки закрытие запрещено. Закрытие вкладки защищено beforeunload. | Тесты dirty/busy guard; поведение browser-native confirm/beforeunload требует E2E |
| A07: Picker | Варианты имеют id, combobox — aria-activedescendant; стрелки/Enter работают по активному пункту, Escape закрывает список, пустой результат объявляется. Необязательное пустое значение доступно клавиатурой. | Тесты клавиатурной логики/ARIA; скринридер не запускался |

Добавлена понятная подсказка о шестизначном коде MFA на русском и современной узбекской латинице. MFA, CSRF, роли и антивирусная политика сохранены. Глобального редизайна и новых зависимостей нет.
