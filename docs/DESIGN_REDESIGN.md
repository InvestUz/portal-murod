# UI/UX: редизайн 0.3.0-rc.2

01.11.2026. Предыдущая версия отклонена владельцем. Изменена реальная React-реализация; серверные правила и Python backend сохранены.

## Изученные источники

- Linear, структура приложения и уровни навигации: https://linear.app/now/how-we-redesigned-the-linear-ui
- Linear, последовательность заголовков и снижение визуального шума: https://linear.app/now/behind-the-latest-design-refresh
- Slite, организация базы знаний: https://slite.com/
- Atlassian, типографика: https://atlassian.design/foundations/typography
- Atlassian, интервалы: https://atlassian.design/foundations/spacing

Открыты первичные страницы; дополнительно просмотрено официальное изображение Linear с основными видами интерфейса. Из источников взяты принципы иерархии и читаемости. Палитра и композиция портала — самостоятельный выбор реализации. Чужие логотипы, скриншоты и шрифты в продукт не скопированы; оформление не является утверждённым брендбуком Toshkent Invest.

## Внесённые решения

- Постоянное левое меню 224px, на промежуточной ширине 208px; мобильное меню раскрывается отдельно и имеет кнопку закрытия. Предусмотрен переход к содержимому с клавиатуры.
- Графит #151b2b, синий #315ce7, рабочий фон #f5f6fa, белые поверхности. Один узнаваемый акцент для действий и текущего раздела. Состояния ошибок/предупреждений отделены от декоративных акцентов.
- Основной текст 14–16px; полезные подписи не мельче 12px. На узких экранах карточки становятся одной колонкой вместо уменьшения букв.
- На главной сначала быстрый доступ к людям, документам и структуре. Новости, дни рождения и документы имеют самостоятельные loading/error/empty состояния.
- HR: добавить сотрудника и импорт; ниже управление сотрудниками/структурой/документами/новостями. Аккаунты и технические операции остаются отдельным разделом администратора.
- В форме сотрудника отдельно основные сведения, контакты с явными переключателями видимости и необязательные фото/этаж/кабинет. Проверка обязательного справочника не принимает простой введённый текст за выбранную запись.

## Что проверено

Пройдены TypeScript, ESLint, Vite production build и PostCSS. В CSS нет font-size ниже 12px. В Chrome открыт отдельный локальный компонентный стенд: реальные Layout, HomeOverview, HrPage, EmployeeCard, DocRow и Picker, с вымышленными props и без backend. Сначала просмотрена статическая генерация компонентов, затем собрана клиентская версия с настоящими React-обработчиками.

Просмотрены широкий экран около 1363px, 1024px, 390px и 320px через отдельные iframe viewport. Для 320px: доступная ширина 305px, scrollWidth 305px; для 1024px: доступная ширина 1009px, scrollWidth 1009px (остальное занимает вертикальная полоса прокрутки). Проверены раскрытие меню, переход к HR с его закрытием, карточки и обязательный Picker. Неверный текст возвращает «Выберите значение из списка»; выбранный пункт снимает ошибку и разрешает отправку тестовой формы. Найденная при просмотре ошибка сетки со skip-link исправлена; мобильный заголовок показывает раздел вместо обрезанного названия компании.

Компонентный стенд не является авторизованным порталом и не подменяет проверку API. На нём не проверялись пароли/MFA, права ролей, реальные данные, сохранение сотрудника, импорт Excel, загрузки/AV/OCR, восстановление, VPN или независимый пентест. Полная доступность/WCAG и проверка всех состояний всех форм также не объявляются пройденными. Backend-отчёт 160 тестов сохранён от 0.3.0-rc.1; он не выдаётся за новый запуск.
