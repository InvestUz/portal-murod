# Браузерная приёмка rc.12

Локально проверены пять замечаний владельца, вход по паролю, EN и сохранение языка, заполненный шаблон HR, переход назад, прокрутка наверх и клавиатура, экран 390 px: [результаты](verification/2026-11-03-user-review-browser.json). [Мобильный экран](verification/images/user-review-mobile-final.png), [кнопка наверх](verification/images/scroll-top-visible.png). Backend настоящий Python/PostgreSQL; браузерная проверка выполнялась на loopback HTTP APP_ENV=test. Production HTTPS и проверка сертификата подтверждены отдельным реальным HTTP-клиентом, а не браузерным TLS-тестом.

Исторические проверки неизменённых сценариев: [rc.11](verification/2026-11-03-rc11-browser.json), [расширенный rc.10](COMPREHENSIVE_CHECK_2026-11-03_RU.md). Они не объявляются новым полным проходом rc.12. Новые credentials/сбросы в браузере не вводились; действующие синтетические логины использовались. В стандартном режиме первая смена и подключение MFA больше не нужны. При включении MFA по отдельной политике ИТ соответствующий ручной сценарий проверяет ИТ.
